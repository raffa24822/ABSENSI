# 📅 Aplikasi Absensi Hari & Cek Kesehatan 2026

Aplikasi Web Interaktif Absensi & Cek Kesehatan Periode **5 Oktober 2026 – 31 Desember 2026**.

## 🌟 Fitur Utama
- **Kalender Khusus 2026**: Mengunci periode 5 Okt - 31 Des 2026.
- **15 Tema Tampilan**: Memiliki 15 variasi tema termasuk *Clear (Polos/Resmi)*.
- **12 Avatar Robot Vector**: Pilihan avatar SVG interaktif.
- **Form Absen di Atas & Kalender di Bawah**: Layout formal dan modern.
- **Fitur Preset "Tetapkan"**: Simpan status favorit untuk 1-Klik Absen Cepat.
- **Notifikasi Audio Chime**: Bawaan Web Audio API (100% berbunyi tanpa file eksternal).
- **LocalStorage Persistence**: Data tersimpan aman di browser tanpa hilang.

---

## 🚀 Cara Upload ke GitHub & Deploy ke Render

### Langkah 1: Upload ke GitHub
1. Buat Repository baru di [GitHub](https://github.com/new).
2. Upload semua file dalam folder ini (`index.html`, `render.yaml`, `package.json`, `.gitignore`, `README.md`).
3. Commit dan Push ke cabang `main`.

### Langkah 2: Deploy ke Render
1. Buka dashboard [Render](https://dashboard.render.com).
2. Klik **New +** > **Static Site**.
3. Hubungkan akun GitHub Anda dan pilih repository `absensi-app-2026`.
4. Isi konfigurasi berikut:
   - **Name**: `absensi-app-2026`
   - **Publish directory**: `./`
5. Klik **Create Static Site**. Website Anda akan langsung online dalam beberapa detik!
